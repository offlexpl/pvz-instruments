Это полезный инструментарий со знакомым интерфейсом, который помогает сотрудникам ПВЗ быстро создавать два важных документа: РАПП и Акт №5. Некоторые поля (Отправитель, Исполнитель и Адрес ПВЗ) сохраняются локально на ПК (не в облаке) и не удаляются при перезагрузке браузера/компьютера, то есть не нужно вводить одно и тоже каждый раз, потому что после каждого изменения, поле сохраняется. А владельцы ПВЗ могут проводить анализ рентабельности ПВЗ за месяц или за конкретный день без сложных действий и вычислений в EXCEL, только загрузить - и смотреть.
